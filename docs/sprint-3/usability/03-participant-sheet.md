# Participant sheets: Kestrel usability test

Print one page per participant and cut or fold it. P6 is a spare, for a lockout or an extra participant.

**Where the values come from.** The booking references are made on test day by
`.\tasks.ps1 usability` (`scripts/data/create_usability_bookings.py`). It prints one line per participant,
`P1  <reference>  <surname>`. Copy each line onto the page with the same number before the first session.
Running the script again keeps the same references (see the [session script](02-session-script.md),
section 2). Every booking is synthetic: a made-up passenger on a made-up cancelled flight.
