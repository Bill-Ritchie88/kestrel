# Policy source texts

The policy corpus (FR-02) is built from the authoritative documents below,
saved **verbatim** as UTF-8 plain text in this folder. Nothing in the corpus is
written by hand or generated by a model; `scripts/ingest_policies.py` only
splits these files at their article headings.

The `.txt` files are third-party documents and are not committed (see
`.gitignore`). To rebuild the corpus, save each page as text with the file
name shown: open the page, select all (Ctrl+A), copy (Ctrl+C), paste into
Notepad and save as UTF-8.

| File | Document | Source |
|---|---|---|
| `kq-conditions-of-carriage.txt` | Kenya Airways General Conditions of Carriage | https://www.kenya-airways.com/en-ke/policies/conditions-of-carriage/ |
| `eu261.txt` | Regulation (EC) No 261/2004 (air passenger rights) | https://eur-lex.europa.eu/legal-content/EN/TXT/HTML/?uri=CELEX:32004R0261 |
| `montreal-convention.txt` | Convention for the Unification of Certain Rules for International Carriage by Air (Montreal, 1999) | https://eur-lex.europa.eu/legal-content/EN/TXT/HTML/?uri=CELEX:22001A0718(01) |

`MANIFEST.sha256` (committed) records the SHA-256 of each file that was
ingested and the date it was saved, so the exact text behind every evaluation
result can be identified. Regenerate it after replacing a file:

```
python scripts/ingest_policies.py --manifest
```
